# UrbanPulse – Smart City Management Platform

UrbanPulse is a smart city civic management platform designed to improve urban services, grievance redressal, civic telemetry, and department coordination across Telangana.

## Features

- Civic Grievance Management
- Smart City Telemetry
- Department Dispatch Management
- GHMC, TGSPDCL and HMWSSB integration
- AI-powered capabilities

## Technologies Used

- React
- TypeScript
- Vite
- Tailwind CSS
- Google Gemini API

## Run Locally

### Prerequisites
- Node.js
- npm

### Installation

1. Clone the repository:
   ```bash
   git clone YOUR_GITHUB_REPOSITORY_URL
   ```

2. Navigate to the project directory:
   ```bash
   cd UrbanPulse
   ```

3. Install dependencies:
   ```bash
   npm install
   ```

4. Configure your environment variables in `.env.local`:
   ```env
   GEMINI_API_KEY=your_api_key
   ```

5. Start the development server:
   ```bash
   npm run dev
   ```

6. Build the project:
   ```bash
   npm run build
   ```

## Deployment

This project can be deployed using Vercel or other compatible hosting platforms.
